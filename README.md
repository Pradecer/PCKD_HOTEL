# PCKD Hotel - Luxury Booking Platform

A modern, full-stack luxury hotel booking application built with React, TypeScript, and Supabase.

## About

PCKD Hotel is a sophisticated hotel management and booking system designed to provide users with an elegant interface for discovering and reserving luxury accommodations. The platform offers seamless country/state/city based location selection and secure authentication.

## Features

- 🏨 **Luxury Hotel Listings** - Browse premium hotels with detailed information
- 🌍 **Location-Based Search** - Filter hotels by country, state, and city
- 🔐 **Secure Authentication** - User authentication powered by Supabase
- 💎 **Modern UI/UX** - Clean and elegant interface built with React
- ⚡ **Fast Performance** - Optimized with Vite for rapid development and production builds
- 🎨 **Responsive Design** - Tailwind CSS for beautiful, responsive layouts
- 📱 **Mobile Friendly** - Works seamlessly on all devices

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Backend/Database**: Supabase (PostgreSQL)
- **Icons**: Lucide React
- **Location Data**: Country State City API
- **Code Quality**: ESLint, TypeScript strict mode

## Getting Started


# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linting
npm lint

# Type checking
npm run typecheck
